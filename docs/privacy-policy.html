1Общая информация

Настоящая Политика конфиденциальности описывает, какие данные может собирать мобильное приложение Евпатория («мы», «наш сервис» или «Приложение») и как они используются.

Приложение предоставляется бесплатно и используется «как есть». Используя приложение, вы соглашаетесь с условиями данной Политики конфиденциальности.

2Какие данные мы собираем

Приложение собирает ограниченный объём технических данных, необходимых для работы сервиса.

Собираем

  • Платформа устройства (Android / iOS)
  • Версия операционной системы
  • Дата и время первого запуска
  • Дата и время последнего запуска
  • Точное местоположение (геолокация)

Не собираем

  • Имя пользователя
  • Адрес электронной почты
  • Номер телефона
  • Платёжные данные
  • Контакты пользователя
  • Иные персональные данные

3Геолокация

Приложение может получать точное местоположение устройства, чтобы отображать текущую позицию пользователя на карте и обеспечивать работу картографических функций.

Данные о местоположении используются только внутри приложения и не сохраняются и не передаются третьим лицам — за исключением случаев, необходимых для работы интегрированных картографических сервисов.

Пользователь может отключить доступ к геолокации в настройках устройства в любое время.

4Как используются данные

Собранные технические данные используются исключительно для следующих целей:

  • Обеспечение корректной работы приложения
  • Базовый технический мониторинг использования
  • Повышение стабильности и совместимости с различными версиями ОС
  • Отображение позиции пользователя на карте
Данные не используются для рекламы, маркетинга или профилирования пользователей.

5Картографические сервисы

Приложение использует Яндекс Карты (Yandex Maps) для отображения карт.

При использовании картографических функций сервисы Яндекса могут обрабатывать техническую или геолокационную информацию, необходимую для отображения карты и определения позиции.

Рекомендуется ознакомиться с политикой конфиденциальности Яндекса для получения дополнительной информации.

6Аналитика

Приложение не использует сторонние системы аналитики.

7Push-уведомления

Приложение может отправлять push-уведомления через Firebase Cloud Messaging (Firebase).

Firebase может обрабатывать техническую информацию устройства, необходимую для доставки уведомлений.

Push-уведомления можно отключить в настройках устройства.

8Передача данных

Мы не продаём, не передаём и не сдаём в аренду пользовательские данные третьим лицам.

Информация может быть раскрыта только в случаях, предусмотренных законодательством.

9Безопасность данных

Мы принимаем разумные технические и организационные меры для защиты информации.

Однако ни один способ передачи данных через интернет или их хранения не может быть полностью безопасным.

10Конфиденциальность детей

Приложение не предназначено для детей младше 13 лет.

Мы сознательно не собираем персональные данные детей.

11Изменения политики

Мы можем периодически обновлять данную Политику конфиденциальности.

Рекомендуется регулярно проверять этот документ на наличие изменений.

Если у вас есть вопросы относительно данной политики, вы можете связаться с нами.
